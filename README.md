# 九号电动智能舆情分析预警系统

本项目面向九号电动社媒与用户社群，建设统一的舆情分析和风险预警能力。第一期统一规划社媒与社群的数据结构和事件口径，优先落地社群模块。

当前已完成项目定义框架，并进入数据与模型可行性验证。公司模型已通过开发机上的合成数据调用测试；生产数据接入与自动化分析仍需完成服务账号、日志留存、数据授权及其他依赖确认。

## 当前结论

- 第一期分析约 500 个企微官方用户群和约 50 个民间微信群。
- 当前消息量约 45 万条每周，历史数据可回溯半年并支持增量获取。
- 第一期只分析文字消息，不处理图片、语音和视频内容。
- 重大风险的目标发现与通知时限为 2 小时。
- 告警由售后服务运营团队人工确认和决定升级，通过飞书通知。
- 处理结论需要回流系统，第一期不建设完整工单闭环。
- 允许用稳定的匿名用户 ID 关联同一用户的不同时段或跨群消息。
- 原始文本和脱敏文本均不得发送给外部模型；生产分析只能使用公司批准并私有部署的模型。
- 开发阶段暂接个人 DeepSeek API，但仅允许使用模拟或公开数据；代码层会拒绝生产社群数据。
- 公司模型服务已确认兼容 OpenAI Chat Completions 接口，当前测试模型为 `deepseek-v4-flash-0731`。
- 公司模型的真实生产群聊开关默认关闭，完成服务账号、日志留存和数据授权确认后才能显式开启。
- 正式服务器为 2 核 CPU、2 GB 内存和 40 GB 云硬盘。该服务器不承担大模型推理，模型应由公司的独立推理服务提供。
- 社媒数据源暂时预留接口，等待确认公司 VOC 系统的数据导出能力。

## 开发验证

当前代码包含可替换的外部 DeepSeek 与公司私有模型网关，不包含真实数据采集或分析任务。无需真实 API Key 即可运行单元测试：

```bash
PYTHONPATH=src python3.11 -m unittest discover -s tests -v
```

公司模型的安全连通性复测使用本地环境变量，不加载 `.env` 文件，也不会打印密钥：

```bash
set -a
. ./.env.local
set +a
PYTHONPATH=src python3.11 scripts/check_company_model.py
```

配置说明见 `.env.example`。在生产治理清单未完成前，保持 `COMPANY_MODEL_ALLOW_PRODUCTION_DATA=false`。个人 DeepSeek 仍只允许处理模拟或公开数据。
