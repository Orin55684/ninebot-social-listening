# 风险列表与手动刷新

风险页拆分后缺少原 `.b-events` 表格样式，导致单元格无间距、时间与来源连成一行。本次为风险列表建立独立样式：问题标题、车型与话题、原声摘要分层；日期和时分分行；来源使用短名称，完整渠道在详情保留；R1/R2/R3 使用不同颜色。保留每页20条与翻页，窄屏表格在自身容器内横向滚动。

取消首页/风险页每10秒轮询与重绘，取消报告任务每4秒自动轮询。首次进入加载，阅读时不自动刷新；右上角“刷新数据”手动获取最新模拟时刻与数据。报告任务通过“刷新生成记录”查看进度。快进、筛选、翻页、保存核验等明确操作仍正常请求数据。

手动刷新保留风险筛选和页码。翻页和筛选统一使用当前页面数据截止时刻，避免后台时钟推进导致分页错位；服务端不接受超出当前模拟时刻的未来数据。搜索输入延迟300毫秒再查询，更新中保留现有列表，避免清空表格造成闪动。

底层模拟时钟仍正常推进；页面“数据截至”表示本次读取时刻。此改动不暂停模拟系统，也不更改模型结论、原始数据或核验记录。
