# 风险分类与预警机制

版本：0.1  
状态：业务评审稿

## 分类原则

系统同时保留“问题主题”和“风险等级”两个维度。问题量高不一定风险高，消息量少也不意味着安全。例如一般续航抱怨可能高频但不紧急，行驶中突然断电或制动异常即使只有一条可信反馈，也应进入高风险核验。

## 一期问题主题

一期分类树以售后团队 8 月 TOP 问题为基础：

| 一级主题 | 当前参考占比 | 二级问题示例 |
| --- | ---: | --- |
| 电池 续航 电量 | 27.0% | 续航虚标或里程不达标；电量骤降或突然掉电；电池鼓包；充电异常；电池计量板通讯异常 |
| 售后 门店服务 | 7.2% | 门店态度或推诿；客服投诉无果；排查不出或反复维修；质保期内拒保；维修后出现新问题 |
| App 智能功能 | 4.8% | 智能服务续费争议；GSM或4G连接问题；App功能异常；防盗报警失效；NFC或蓝牙解锁故障 |
| 异响 | 4.8% | 车头或前轮异响；刹车或龙头异响；转把或电机异响；减震异响；充电器异响 |
| 动力 油门 转把 | 4.7% | 转把不走或无反应；行驶中断电或降功率；升级后动力衰减；无法停稳或顿挫；起步延迟或转把故障 |
| 仪表 显示屏 | 4.0% | 仪表不亮或黑屏；续航显示不准；主题无法设置；导航等功能缺失；故障码频繁出现 |

分类树必须允许新增主题、车型差异和“其他/待确认”，不能将 TOP 6 固化为永久范围。

## 拟定风险等级

以下分级用于启动评审，最终名称和触发条件由售后服务运营团队确认。

| 等级 | 定义 | 处理目标 |
| --- | --- | --- |
| R1 紧急 | 可能涉及人身安全、火灾、失控、制动失效、行驶中断电或快速扩散的重大事件 | 立即进入人工核验，符合条件时确保2小时内通知 |
| R2 高 | 同车型同问题集中出现、投诉量异常上升、跨群传播或可能形成公开舆情 | 优先人工核验，符合条件时2小时内通知 |
| R3 中 | 持续重复的产品、服务或功能问题，影响较广但暂未出现紧急安全信号 | 纳入当日热点和待处理列表 |
| R4 洞察 | 一般咨询、建议、需求和低强度体验反馈 | 纳入周月趋势，不触发即时告警 |

## 风险判断因子

- **固有严重度：** 是否涉及人身安全、火灾、制动、失控、行驶中断电等红线。
- **消息趋势：** 相较同车型、同问题历史基线是否突然增长。
- **影响范围：** 涉及的匿名用户数、群数、车型和地区范围。
- **传播迹象：** 是否出现跨群转述、截图传播或重复话术。
- **证据质量：** 是否为亲历反馈，是否包含可核验上下文，是否可能是转述或无关讨论。
- **业务状态：** 是否已有已知故障、活动、升级或售后事件可以解释。

## 触发策略

一期采用“红线规则与趋势规则并行”的方式：

1. 红线规则处理低频高风险信号，避免安全问题被消息量阈值淹没。
2. 趋势规则识别同车型、同部件或同问题在时间窗口内的异常增长。
3. 模型负责理解语义、形成结构化标签和摘要，不单独决定是否对外升级。
4. 所有自动告警先进入售后服务运营团队人工确认。
5. 阈值在历史回放和标注评估后确定，不在 PRD 阶段凭经验写死。

## 告警卡片最低内容

- 事件标题和建议风险等级。
- 首次出现时间、最近更新时间和目标时限。
- 涉及车型、部件、群数和匿名用户数。
- 消息量及相对历史基线的变化。
- 系统触发原因和不确定项。
- 脱敏后的代表性证据。
- 人工确认、驳回、调整等级和填写结论的入口。

## 反馈标签

人工回流至少记录：系统分类是否正确、是否真实事件、最终风险等级、是否需要通知、是否重复事件、误报原因和业务处理结论。第一期只沉淀反馈，不自动触发模型训练。
