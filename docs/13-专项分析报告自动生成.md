# 专项分析报告自动生成

## 目标与模板

按用户提供的《M3挡泥板_专项话题整合_liquidglass_20260916.html》结构实现可重复生成的专项分析报告。复用液态玻璃布局与三个视图：态势总览、重点内容、问题洞察。附件中的固定数量、七月数据和结论不作为系统事实；每次从选定时间范围的真实数据重新计算。

## 使用方法

在本地演示的「报告中心」顶部进入「专项分析报告」：

1. 填写报告标题、目标车型或对象及别名、分析需求、检索问题词。
2. 选择八月内的日期范围与来源（默认全部四来源）。检索词用逗号分隔；可补充近义表达，避免只填“安全”“售后”等过宽泛词。
3. 点击「生成专项分析报告」。后台执行，页面显示检索数量、已精筛数量、生成阶段和完成入口。
4. 完成后打开交互报告，查看趋势、渠道、原声、洞察与建议。每项洞察和建议均链接到原文。
5. 在报告内按来源、话题、关注类别、关键词筛选；可单独查看不计入统计的「关联待核实」记录。
6. 下载单文件HTML（含交互及完整原文）、JSON，或导出当前筛选结果CSV。打印仅输出当前视图，可存为PDF。

需要周期产出时，选择日/周/月并保存「专项周期配置」，再点击「模拟周期运行」。系统按自然周期切分所选日期，首尾可能是不完整周期；每期独立生成上述完整分析报告。当前为八月历史数据回放，不是已接入定时调度或真实采集接口。

## 生成流程与模型

需求与明确的检索范围 → 公司模型规划子问题主题 → 四来源原文检索 → 模型逐条精筛 → 程序统计 → 模型综合分析 → 按段复核引用与表述 → 液态玻璃报告。

模型使用项目 `.env.local` 中配置的公司私有服务，当前为 `deepseek-v4-flash-0731`。需求规划、逐条精筛和综合分析都使用此服务，不调用个人外部模型。每批最多8条反馈、最多8个并发请求，规划和重试等所有调用共用40 RPM全局限速；收到429后至少等待60秒。仍低于用户规定的60 RPM上限。

逐条精筛包含：相关 / 关联不明 / 不相关、情绪、子问题、关注类别、标题、理由。正向关联须有目标词在原文或群名称中支持；群背景并不等于原文确认车型实物。原始字段只读，不覆盖既有风险分析或人工核验状态。

模型给出的原文摘录必须能在源文本中找到；若其改写摘录，系统使用源文本中检索词附近的精确片段替代并记录依据。弹窗始终展示完整原文。模型输出缺失条目、ID错误或分类字段不合规时重试，不凭空补充分析。

综合分析输入为整个检索集合的已校验统计和最多约24条、覆盖子问题与来源的代表原声。输出核心发现、建议行动与限制，引用的ID必须属于本次证据。没有足够相关证据时明确显示未检出，不生成虚构结论。

## 统计口径

- 统计单位是消息，不是去重事故或用户；不能推算产品故障率。
- 负面情绪为「愤怒 + 失望」，分母为纳入的相关消息；不使用旧R1–R3风险等级代替情绪。
- 关联待核实、不相关的记录分别计数；不计入相关量、负面率和来源构成。
- 总览的近3天、近一周以所选结束日期为锚点，趋势、数量和渠道使用同一窗口。
- 来源没有匹配记录时显示零，不用其他月份或模板中的数字填充。
- 相似原声与同日讨论不等于传播链、共性缺陷或已发生事故；分析结果待人工核验。

## 本地实现与数据

- `src/ninebot_listening/topic_reports.py`：需求、异步任务、规划、原文检索、精筛缓存、计算、归纳、周期配置、渲染。
- `design-samples/dist/topic-report.html`：从用户附件提取布局样式、替换全部固定数据和结论后的单文件模板。
- `design-samples/dist/topic-studio.js`：系统内的专项生成入口与进度。
- `data/august-demo/topic-reports/jobs.db`：任务、周期配置和精筛缓存。
- `data/august-demo/topic-reports/<id>.json`：报告事实与模型产出，包含私有原文，仅存本地。

原文在HTML/JSON中保留，报告文件包含私有数据。模板不加载外部字体、脚本或图片。原文及模型文字按文本渲染；CSV提供公式注入防护。

验证：52项测试覆盖数据统计、情绪分母、证据ID、原文摘录、HTML转义、筛选CSV、缓存、六周期切分及接口CSRF；页面检查覆盖导航、原文弹窗、来源筛选、周期配置保存与390px窄屏。模型复核不等于人工事实核验，原文和引用保留供人工复查。

样品：M3挡泥板八月专项分析。候选1583条均完成专项精筛，相关473条（企微452、公域VOC11、意见建议10、微信导出0），关联待核实370条、排除740条；负面情绪122条，占纳入相关消息25.8%。这些是本次检索与机器精筛口径，不等于所有M3用户反馈或实际故障率。样品含一项明确标注待人工补充的行动段落。
