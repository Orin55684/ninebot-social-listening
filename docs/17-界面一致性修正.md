# 界面一致性修正

- 核验记录页拆分为统一页头与内容卡片。无记录时展示图标、说明和前往核验入口；有记录时按时间线展示结论、等级、依据和时间。只使用真实核验记录，不填充演示记录。
- 页面内单选下拉框使用同一套玻璃菜单，覆盖风险筛选、数据浏览、报告表单和核验弹窗。原生字段保留表单值与必填校验；支持方向键、Enter、Escape、Tab及点外侧关闭。菜单使用顶层弹出层，避免被弹窗或卡片裁切。
- 移除前端模拟时间调整栏及其操作代码，不再提供暂停、快进、倍率或重置入口。后端模拟时钟继续运行，前端仅保留“数据截至”和手动刷新。
- 保持无定时数据刷新；下拉组件仅在DOM结构变化时初始化，不轮询接口。

浏览器核对空状态、合成记录时间线、筛选与键盘交互；未向真实核验库写入测试记录。
