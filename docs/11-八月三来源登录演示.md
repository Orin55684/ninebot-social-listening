# 八月三来源登录演示

> 本文记录早期三来源阶段。当前本地版本已扩展为[四来源、原始数据与自动报告](12-四来源原始数据与自动报告.md)，原文展示与导出范围以该文档为准；尚未同步本轮更新至服务器。

## 范围

只维护 demo1。三个来源为企微社群、民间微信群导出和四平台 VOC；人工核验是后续环节，不是来源。旧样品入口转到受保护的新入口，暂不删除其他设计文件。

全量导入可用八月文本，再从每个来源选择 12 条候选尝试公司模型分析。安全词优先和普通候选共同入样；这不是随机无偏样本，不能用来推算全月风险比例。成功、失败和未处理应当分别核对，模型接口限流时不伪造结果。

VOC 采用“负面 AND 已研判 AND 舆情状态非无需/无须处理”，仅抖音、小红书、快手、B站。按发布时间筛八月。评论不拼接其他评论作为上下文；系统无法补齐原帖对话。

微信群 JSONL 优先，Markdown 补足缺失群日；排除同名企微群及已知官方、核心、售后名称。剩余群归属仍需人工确认。覆盖天数按照实际消息日期显示，不把文件名当作完整覆盖证明。

## 运行

在项目目录设置 `PYTHONPATH=src`，使用 Python 3.11：

1. `scripts/august_replay.py import --wecom <只读原库> --wechat <原始数据目录> --voc <导出CSV>`：导入独立的本地回放库。
2. `scripts/august_replay.py analyze --approve-historical-demo --per-source 12`：读取本机公司模型配置。已成功样本不重复调用；失败可以续跑。仅在公司网络可达时运行。
3. 分析结束后运行 `scripts/august_replay.py export`：导出汇总、分析证据和数据边界；不导出全量原始消息。
4. 将快照放在受限的服务器应用目录，而非静态公开目录；重启演示服务加载快照。人工核验数据库独立保存，更新页面不能覆盖它。

样本集合保存在回放库 settings 中。改变 `--per-source` 不会扩大已建立的集合，扩大分析需要另行明确管理样本计划。

## 在线边界

用户已授权本次演示数据上传腾讯云并增加登录保护。页面、样式和所有 API 统一通过 HTTPS 和服务器认证保护。后台只监听回环地址；只允许明确列出的静态文件，不能下载快照文件、原库或环境配置。服务开机启动，独立系统用户运行。

本次使用共享演示账号，不是企业单点登录或人员级权限体系；不适合作为生产权限审计。密码仅保存在本机忽略目录中的访问说明，不写进 Git。公司模型密钥和全量原库不上传服务器。

确认或驳回必须由评审人员操作。确认 R1/R2 会保存模拟通知记录；驳回或降级会移除该记录。没有连接通知渠道，不会真的发群消息。核验意见、历史和模拟通知保存在服务器独立 SQLite 中。

## 验证

`PYTHONPATH=src python3.11 -m unittest discover -s tests -q`

覆盖 VOC 业务过滤和幂等、独立评论上下文、两种 Markdown 格式、未分析原文不导出、CSRF、核验及模拟通知状态、禁止任意文件读取。部署后还需检查未登录和错误密码均返回 401，正确密码可读页面和接口，原库/快照/环境文件路径返回 404。

演示不等于全量模型研判，也不等于生产实时系统。首次发布保留待核验状态，不由开发过程代替业务人员作出真实结论。
