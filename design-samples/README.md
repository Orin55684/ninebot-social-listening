# 九号舆情 · 设计样品

本目录同时保存离线设计样品和 demo1 页面。离线设计样品不连接社群数据库、VOC 文件、模型服务或通知服务，案例、数量、趋势和分析解释均为虚构。`august.html` 是 demo1 的实际数据界面，需通过历史回放服务运行。

打开 `dist/index.html` 即可使用，无需安装软件，也可以通过本地 HTTP 服务访问。

## 参考设计版

打开 `dist/reference.html` 查看参考小红书笔记《18组配色与排版｜网页WEB看板界面设计》图 1、2、3 的新增样品。参考链接：https://xhslink.cn/o/3TMzPm2JHIg 。仅借鉴配色与布局，不复制图片或字体文件。

- 01 蓝黄总览：亮蓝主视觉带、暖黄强调、紧凑图表。
- 02 银灰工作台：银灰分层、炭黑文字、荧光绿点缀，支持搜索和核验。
- 03 橙色关联视图：灰白关系视图、两侧面板、橙色详情，支持主题切换。

参考版保持纯静态且没有外部资源依赖。腾讯云仅应部署白名单内的 HTML、CSS、JS 静态资源，禁止上传数据库、CSV、SSH 密钥、环境配置或整个项目目录。

- A 指挥中心：深色态势总览，趋势 → 重点事件 → 核验证据。
- B 业务工作台：浅色操作界面，待办 → 搜索/筛选 → 核验 → 模拟确认。
- C 月度观察：编辑式报告，业务发现 → 案例解释 → 原文证据。
- 方案对照：比较三种信息顺序，可以混搭页面。

## 交互边界

搜索和来源筛选可用；事件详情支持键盘 Escape 关闭；确认操作仅保存在本页内存中，刷新即重置。所有通知均为模拟，无网络发送，也不修改项目正式数据。

公域独立评论明确标注无上下文；不补造对话，不将同类问题直接认定为跨渠道传播。顶部持续展示虚构数据标记。

本轮不包含真实数据分析、账户权限、生产预警或已发布的共享服务。请先评审视觉与内容组织，再决定接入方案。

## 液态玻璃本地版

直接用浏览器打开 `dist/liquid-glass-standalone.html`。这是包含全部样式和交互的单文件版本，可以单独复制，离线使用，无需启动服务。

- 冰蓝与暖桃渐变、玻璃环主视觉、半透明卡片、可调玻璃透明度。
- 三个视图：态势总览、风险核验、问题洞察。
- 支持时间切换、关键词搜索、来源与状态筛选、详情弹窗、模拟核验、持续观察、提醒和重置。
- 全部案例与指标为虚构示例；状态仅保存在当前页面内存中，刷新重置。
- 已检查桌面及 390px 窄屏显示；仅在本地制作，未部署。

可编辑源文件为 `dist/liquid-glass.html`、`dist/liquid-glass.css`、`dist/liquid-glass.js`；修改后需同步生成单文件版本。

## demo1 当前默认 UI

`august.html`、`august.css`、`august.js` 已采用液态玻璃设计；通过 `scripts/august_server.py` 原入口加载真实历史快照与核验状态。当前本地预览为 `http://127.0.0.1:8882/`。本次 UI 替换仅在本地完成。

离线 `liquid-glass-standalone.html` 保留为设计参考，不承担 demo1 的真实数据读取和持久化核验。

当前 demo1 已接入八月四来源（企业微信、微信导出、VOC、意见建议），新增数据浏览、分类标签与报告中心。风险详情展示实际原文及来源字段；支持时间、渠道、话题筛选后的完整 CSV/JSON 导出，以及专项日/周/月报告。周期流程为用户触发的历史模拟，不连接真实外部接口或后台定时任务。具体数据范围与操作见 `../docs/12-四来源原始数据与自动报告.md`。
